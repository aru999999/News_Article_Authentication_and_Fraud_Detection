# News Article Authentication and Fraud Detection

IDEAS Autumn Internship 2026 project. An end-to-end machine learning pipeline
that classifies news articles as real or fake.

## What it covers
- Data preparation: merging, labelling, text cleaning, outlier removal
- TF-IDF features and a Logistic Regression baseline
- K-Means clustering and Truncated SVD visualization
- Random Forest with 5-fold cross-validation
- MLP neural network with hyperparameter tuning
- Evaluation: F1-score, confusion matrix, business-cost metric, ROC-AUC

## Dataset
Fake and Real News Dataset on Kaggle. Download Fake.csv and True.csv and
upload them to the notebook's folder (or Colab's file panel) before running.
link: https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset
## Tools
Python, pandas, NumPy, scikit-learn, TextBlob, matplotlib, seaborn
